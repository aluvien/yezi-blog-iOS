# 叶子 · 杂志风格原生实现

方向：纸白 `#F5F2EB`、墨黑 `#252520`、朱红 `#B64432`。宋体只承担页面标题、文章标题与絮语正文，表单、操作和辅助信息使用系统字体。深色使用暖黑背景与低饱和朱红，不直接反转浅色。

## 实现范围

- 四个主入口：絮语、文章、评论、管理。平面底栏，保留各页导航状态；子页面收起底栏，返回后恢复。
- 絮语与文章采用开放式排版、细分隔线和右下角方圆写作按钮；搜索按需展开。絮语顶部保留音乐快捷入口，相册和草稿位于更多菜单。
- 评论保留实际的全部／待审核／已通过语义，以及通过、回复、垃圾标记和删除操作。效果图的「待回复」不冒充现有审核接口能力。
- 管理采用真实站点信息、三列统计和整行入口。文件仍在管理中。站点信息仅首次进入加载，不随着每次返回设置重复发起请求。
- 文件图片筛选采用自适应网格；其他文件保留可阅读的列表，菜单提供详情、引用、分享、复制和删除。
- 基础设置改为线性表单，保存移到右上角；辅助功能大字体自动改为上下排列。音乐、外观、更新、作品、分类、引用、关于等页面共用同一套色彩、标题、按钮和小圆角。
- 文章编辑采用参考图的单排底部工具栏：加粗、标题、链接、列表｜图片、音乐、预览；移除顶部模式切换和旧双层工具栏。取消／发布使用轻量文字按钮。撤销、重做、其余格式及发布设置收在标题旁的选项菜单，预览关闭后保留正文和选区。正文仍是可编辑的 Markdown 源码，图中排版不代表已实现所见即所得编辑。

## 字体与演示图片

- 字体来自 [Google Fonts 官方 Noto Serif SC](https://github.com/google/fonts/tree/main/ofl/notoserifsc)，原文件未经裁剪，随 App 离线注册；许可一并打包在 `YeziApp/Fonts/OFL.txt`。
- 生成的演示照片保存于 `YeziApp/Assets.xcassets/EditorialPreview.imageset/sunlight.png`，由内置 image_gen 生成，仅由 DEBUG 离线样本使用，不替换用户实际照片。
- 照片提示词：一幅横向 4:3 胶片摄影，温暖午后阳光照射赭色老墙及木窗，左上角树叶投下真实清晰的影子，克制配色、细微胶片颗粒，无文字、无 UI、无人像。
- AI 生图已接入可配置的 CPA/OpenAI Images 接口。服务地址、模型和密钥在生图页右上角设置，配置仅存钥匙串；生成、取消、预览、重新生成和插入正文均有实际实现，可同时设置封面。真实 CPA 尚未提供连接配置，因此未完成真实服务联调。DEBUG 验收使用受控接口返回演示照片，截图明确标注为离线结果，不把该照片当作 CPA 实际生成的结果。
